Never silence a lint with `#[allow(...)]`. When an exception is genuinely
justified, write `#[expect(lint, reason = "...")]`: the reason is mandatory, and
the compiler reports the attribute as unfulfilled once the code no longer
triggers the lint, so a stale exception cannot outlive its cause.

Fix the code first. An `#[expect]` is a documented decision, not a way to make a
warning go away.

## Bad

```rust
#[allow(clippy::too_many_lines)]
fn update(world: &mut World) { … }
```

## Good

```rust
#[expect(
    clippy::cast_possible_truncation,
    reason = "tile indices are bounded by MAP_SIZE, which fits in u16"
)]
let index = position.x as u16;
```

## Exceptions

- Attributes generated by external macros, which Clippy already ignores
